# 用 Seedance 2.5 Flash 实现高保真参考视频复刻：完整工程教程

> **适用目标**：在只使用 **`doubao-seedance-2-5-flash-261115`**（最高 720p、成本可控）的前提下，对一条 `1080p / 60fps / HLG` 的复杂运镜参考视频完成**局部主体替换**（本案：保留原片递归螺旋景观、运镜倾斜、草坡树林与时间节奏，仅将成人骑行者与自行车替换为背向镜头、低坐姿蹬踏三轮车的小男孩），并达到**姿态动作准确、1080p 原背景清晰不重绘、HDR/HLG 观感一致**的高保真交付标准。

---

## 一、先复盘：为什么直接调用 Flash 视频编辑容易翻车？

在同款模型 `doubao-seedance-2-5-flash-261115`（720p、`303,300` tokens）下，V2 版虽然“形式上接近了”，但存在 4 个非常典型的工程瓶颈：

| 痛点 | V2 的实际表现 | 根因诊断 | 本教程（V3-Flash）的解法 |
|---|---|---|---|
| **1. 姿态与车体畸变** | 多帧小孩偏站立、双腿垂直下垂、车座像“高脚椅”或滑板车 | 原片是成人骑高座公路车（垂直伸直腿部光流）；V2 角色图是高拱架侧视图且缺正后方主视角，提示词又与原动作冲突 | 重构 4 张参考图（先锁**正后方低坐姿宽后踏板**，再补 **45° 机械结构** + 两张错开踩踏相位的场景图），提示词显式解除成人姿态绑定 |
| **2. 参考图带偏色调** | 画面整体偏暖偏黄、草地发黄 | V2 的场景参考图 `target-scene.png` 被图生图顺带重绘了云层与草地色调 | 对场景参考图执行**背景像素级锁定（Pixel-Lock）**：仅局部羽化回贴主体与阴影，外围背景 MAE < `0.004` |
| **3. 720p 背景软化重绘** | 树叶、草坡和螺旋云缘变软，非原背景像素锁定（背景 MAE 约 `16.0`） | 视频扩散模型整帧重构 720p 不可避免会抹平高频纹理 | 利用 `edit` 模式的亚像素时空锁定特性，做**全自动 1080p 原背景分层合成**（DP 对齐 + DIS 光流半帧 + ECC 配准 + 5 层拉普拉斯融合），背景 MAE 降至 **`0.366`** |
| **4. macOS HDR/SDR 色差** | QuickTime 并排播放时原片通透明亮、生成片发灰发平 | 原片为 `8-bit yuv420p` 携带 `bt2020nc / bt2020 / arib-std-b67 (HLG)` 流标记；模型输出丢失标记（`unknown`），播放器按 SDR 渲染 | 保持在原始解码像素域完成编辑与局部色彩匹配，导出时精确补齐一致的 **HLG / BT.2020 流级色彩元数据** + 无损复混原片 AAC 音轨 |

## 三、Phase 0：动手前的原片法医级体检（避开 80% 返工）

在写提示词或生图之前，必须先用 `ffprobe` 和抽帧把原片摸透，避免盲猜参数：

```bash
ffprobe -v error -show_streams -show_format reference-original.mp4
```

本案原片关键事实（决定后续所有技术决策）：
1. **视频流**：`1920×1080`，`60 fps`（429 帧），`7.15s`，`h264`，`yuv420p`（8-bit）。
2. **色彩三元组**：`color_range=tv`，`color_space=bt2020nc`，`color_primaries=bt2020`，`color_transfer=arib-std-b67`（HLG）。
   - **重要避坑**：不要盲目对这类 8-bit HLG 源片跑 `ffmpeg zscale + tonemap` 转 SDR 再送模型！V2 试验已证明直接色调映射会导致云层高光爆白和草地褪色。Seedance 内部直接按原始解码像素域处理，因此**直接送未修改原片**，并在最终封装阶段还原色彩标记是保真度最高的做法。
3. **音频流**：`aac`，`48000 Hz`，立体声，`7.168s`。因此 API 请求设 `generate_audio: false`（省算力且避免生成杂音），后期直接无损复混原音轨。
4. **镜头与遮挡核验**：逐秒抽帧确认全片为单镜跟拍，骑行者全程位于开放土路与草坡走廊上，**没有任何近景树干从骑行者前方横穿遮挡**——这一条直接决定了 Phase 3 可以用“追踪走廊 + 多频段金字塔融合”做到零人工抠像的全自动 1080p 分层合成。

## 四、Phase 1：参考图工程（决定 Flash 生成质量的 60%）

Seedance 2.5 Flash 的 `edit` 模式支持多张 `reference_image`（上限 10 张）。核心原则是：**每张图职责单一、视角与镜头匹配、绝不混入背景污染，绝不用多视图拼图（容易诱发视频分屏伪影）**。

### 4.1 角色与载具结构图（2 张单视图，纯灰棚底）

1. **图 1 — 正后方跟拍主视角（`char-rear-straight.png`）**
   - **为什么它是胜负手**：原片约 80% 时长都是正后方略俯视跟拍。如果只给侧后 3/4 图，Flash 在正后方镜头下会把小孩的腿拉成与原成人一样的垂直长腿。
   - **必须锁死的几何锚点**：
     - 4–5 岁紧凑幼儿身材，严格背对镜头（不露脸），棕短发、暗砖红罗纹针织毛衣、深蓝牛仔裤、棕色系带小皮鞋。
     - **低矮红色金属车座** + **宽大横向红色金属后脚踏板** + 左右分开的两只米白圆盘轮毂小后轮（彻底消灭高脚拱架！）。
     - **双膝明显呈 `< >` 向外向前弯曲**，一高一低，双脚稳踩曲柄踏板——从正后方一眼就能看出“坐着蹬踏”，物理上堵死“站立/滑板车”畸变路径。
     - 光照方向与原片对齐：左上方暖日光、右下方冷阴影。

2. **图 2 — 左后 45° 机械结构图（`char-rear-3quarter.png`）**
   - **生成方式**：以图 1 作为唯一参考图调用 **Seedream 5.5**（`doubao-seedream-5-5-261028`，`size: "2K"`），严格保持同一角色、同一毛衣/裤子/鞋和同一宽后踏板红三轮车。
   - **职责**：把正后方视角下被腿部遮挡的**大尺寸辐条前轮、前轮曲柄踏板、双脚踩踏位置、宽银色弯车把**完整交待给视频模型，保证转弯与连续蹬踏时机械结构不穿帮。

### 4.2 场景融入关键帧（2 张，必须做“背景像素级锁定”）

挑选原片最具代表性的两个瞬间（本案选 `1.5s` 大倾角下坡弯道、`5.0s` 阳光直道），分别抽原片 1080p 帧，用 `[原片帧, 图1]` 调用 Seedream 5.5 做局部替换，**刻意让两帧处于相反的左右腿踩踏相位**（`1.5s` 左膝略高，`5.0s` 右膝抬高），暗示视频模型腿部需要交替运动。

**关键一步——背景像素级锁定（Pixel-Lock）**：
任何图生图模型编辑整帧时，都会对天空、白云和草地做微弱重绘和暖色偏移。在送入 Seedance 之前，用脚本只取编辑图里“主体 + 投影 + 旧骑行者擦除区”的椭圆区域，先按外缘环带与原片对齐色温/亮度，再做大半径高斯羽化回贴到 **100% 未修改的原片 1080p 帧**上：

```python
# 核心思路：环带校色 + 大半径高斯羽化回贴到原片 1080p 帧
outer = cv2.ellipse(zeros, center, (int(rx * 1.35), int(ry * 1.35)), 0, 0, 360, 255, -1)
inner = cv2.ellipse(zeros, center, (int(rx * 0.85), int(ry * 0.85)), 0, 0, 360, 255, -1)
ring = (outer > 0) & (inner == 0)

# 按环带均值/标准差对齐局部色彩，消除拼接亮度台阶
for c in range(3):
    mo, so = orig[:, :, c][ring].mean(), orig[:, :, c][ring].std() + 1e-5
    mr, sr = edited[:, :, c][ring].mean(), edited[:, :, c][ring].std() + 1e-5
    edited_cm[:, :, c] = np.clip((edited[:, :, c] - mr) * (so / sr) + mo, 0, 255)

mask = cv2.GaussianBlur(ellipse_mask, (151, 151), 45)[:, :, None]
pixel_locked = np.clip(edited_cm * mask + orig * (1.0 - mask), 0, 255).astype(np.uint8)
```

实测两张场景参考图（`scene-key-1.5s.png`、`scene-key-5.0s.png`）的外围背景 MAE 仅为 **`0.0035` / `0.0037`**（满量程 255），彻底杜绝参考图带偏视频色调。

## 五、Phase 2：无冲突提示词与 Seedance 2.5 Flash API 调用

### 5.1 写好 `edit` 提示词的 4 条核心法则

1. **逐个绑定参考素材的边界**：
   - `图片1`、`图片2`：只定义人物服装、低矮坐姿和三轮车机械结构，明确声明“不采用其灰棚背景或主体大小”。
   - `图片3`、`图片4`：只作为约 1.5s 与 5.0s 处的尺度、低坐姿与光影融入参考，明确声明“**不作为首帧，不复制为静止画面**”。
2. **显式解除原主体的姿态绑定（关键破局句）**：
   - 必须明确写：“**允许彻底改变原成人骑行者的身高、腿部伸直动作和细长自行车轮廓，完全替换为紧凑低矮的幼儿坐姿与宽后轮三轮车**”。如果不写这句，模型会在“保持原动作”和“换成三轮车”之间打架。
3. **用可观察的机械运动替代抽象词**：
   - 用“臀部牢牢坐在低矮红车座上，双手稳握银色弯车把，双膝始终明显向前向外弯曲，双脚紧贴前轮曲柄踏板做有节奏的左右交替圆周蹬踏，上身随蹬踏和转弯微微自然起伏，三只轮胎全程贴地连续滚动”替代笼统的“自然骑行”。
   - 明确负面禁止：“禁止直腿站立骑行、禁止出现高脚车座或滑板车形态、禁止残留成人骑行者、头盔或成人自行车轮廓”。
4. **写死冲突裁决规则**：
   - “参考图与视频发生冲突时，背景、色调、运镜与节奏以视频1为准，人物与三轮车低坐姿及机械结构以图片1、图片2为准。”

### 5.2 推荐的省钱验证节奏（先短后长、先低后高）

> **最佳实践**：面对新素材或新提示词时，**不要一上来就跑全长 720p**！

1. **阶段 A — 快速低成本验证（推荐先做）**：
   - 用 `ffmpeg` 截取原片动作最具代表性的 `2–3 秒` 片段（例如 `3.0s–5.5s` 含树影与直道蹬踏）：
     ```bash
     ffmpeg -y -ss 3.0 -t 2.5 -i reference-original.mp4 -c copy ref-clip-2.5s.mp4
     ```
   - 调用 `doubao-seedance-2-5-flash-261115` + **`resolution: "480p"`**，单次成本仅约全长 720p 的 1/5。
   - 快速检查：坐姿是否够低、蹬踏是否交替、三轮结构是否稳定、比例是否合适。
2. **阶段 B — 正式全长生成**：
   - 确认验证片达标后，保持参考图与提示词不变，切换为完整 `reference-original.mp4` + **`resolution: "720p"`** 执行**唯一一次**正式 POST。

## 六、Phase 3：720p Flash 变身 1080p 原片级质感的高保真后期（核心黑科技）

很多人以为 Flash 最高只有 720p，背景糊了就没救。但我们对原片与生成片做了帧级测绘后发现一个关键规律：

> **Seedance 2.5 Flash 的 `edit` 模式在时间与空间上与原片近乎 1:1 锁定**（中位偏移仅 `dx=+0.09px, dy=+2.26px`）！

这意味着只要补齐一套全自动 Python + OpenCV + FFmpeg 后期管线（见 `postprocess.py`），就能用 **零人工抠像、零额外模型费用** 把背景直接恢复到 **100% 原始 1080p 清晰度与 HLG 色彩**。整套管线包含 6 个精密环节：

### Step 1：单调动态规划（DP）时序对齐
用画面**上半部分 50%**（纯天空与递归螺旋，完全不含骑行者）计算生成片 169 帧与原片 429 帧之间的 MAE 代价矩阵，施加单调递增约束（因 `60fps / 24fps = 2.5`，允许步长 `{1, 2, 3, 4}` 并轻微偏好 `2.5`），保证时间绝对单调、无回跳卡顿。

### Step 2：双向 DIS 光流半帧合成（消除 60→24fps 的 3:2 抖动）
- **隐藏坑点**：因为 `60 / 24 = 2.5`，生成片的偶数帧刚好落在原片整数帧上，但**奇数帧恰好落在两帧 60fps 原片的正中间（`k + 0.5`）**！如果强行取最近整数帧，在 `0.6s–2.2s` 快速压弯转场时会产生 5–9 像素的 3:2 下拉微抖。
- **解法**：对每一帧比较整数原帧与相邻两帧中点的误差；当半帧更匹配时，用 OpenCV `DISOpticalFlow` 双向光流在原片相邻两帧之间插值出锐利的 `t + 0.5` 帧（本案自动合成 `108/169` 帧精准半帧），让原片背景的运动节奏与 24fps 前景严丝合缝。

### Step 3：亚像素欧氏刚体配准（`phaseCorrelate + ECC`）
先用 `cv2.phaseCorrelate` 估计粗平移，再用 `cv2.findTransformECC(..., cv2.MOTION_EUCLIDEAN)` 在背景区域求解亚像素级平移 + 小角度滚转（带旋转 `≤ 2.5°` 与位移 `≤ 20px` 安全限幅），将生成片精准对齐到对应原片帧。

### Step 4：主体 + 投影 + 旧骑行者擦除走廊自动追踪
在草坡/土路搜索窗口内融合两类线索：
1. 生成片与原片的帧差能量（天然同时囊括“旧成人擦除区 + 新小男孩/三轮车 + 阴影变化”）；
2. 砖红毛衣与红三轮车的色度线索 `clip(R - 1.05 * max(G, B))`。

求加权质心与 98 分位覆盖半径，向右下方偏移 `+0.18 * rx` 以完整罩住低角度阳光投在草地上的长投影，再对整条轨迹 `(cx, cy, rx, ry)` 做时间轴高斯滤波（`sigma=4.5~6.0`），确保合成窗口丝滑移动、零边缘闪烁。

### Step 5：环带色彩匹配 + 5 层拉普拉斯金字塔多频段融合
直接用普通 alpha 羽化容易在亮草地上看出柔和的“椭圆色斑”。采用 **局部环带校色 + Burt & Adelson 5 层 Laplacian Pyramid Blend**：
- 在蒙版外围环带计算局部亮度/色彩增益，将全局平滑增益与局部环带增益按 `0.5 : 0.5` 融合，既无缝匹配脚下土路和草皮色温，又不改变小男孩红毛衣和蓝牛仔裤的真实发色；
- 用 5 层拉普拉斯金字塔分频融合，低频照度大半径过渡、高频细节保持锐利，**完全看不出任何拼接边界**。

### Step 6：HLG / BT.2020 流级色彩标定 + 原片音轨无损复混
直接通过管道单遍写入 FFmpeg，零临时文件，并精确对齐原片的色彩三元组和 AAC 音频：

```bash
ffmpeg -y \
  -f rawvideo -vcodec rawvideo -s 1920x1080 -pix_fmt bgr24 -r 24 \
  -i - \
  -i reference-original.mp4 \
  -map 0:v:0 -map 1:a:0 \
  -c:v libx264 -preset slow -crf 15 -pix_fmt yuv420p \
  -color_range tv -colorspace bt2020nc -color_primaries bt2020 -color_trc arib-std-b67 \
  -x264-params colorprim=bt2020:transfer=arib-std-b67:colormatrix=bt2020nc \
  -c:a copy -shortest -movflags +faststart \
  final-composited-1080p-with-audio.mp4
```

同时建议保留**三份交付对照**：
- `final-composited-1080p-with-audio.mp4`（主推荐：1080p 原背景分层合成 + HLG + 原音轨）

## 八、复用到其他参考视频的通用 SOP 与边界说明

### 最适合直接套用本教程的场景
- 单镜头或切镜后的逐镜主体替换（人物换角、商品替换、车辆/道具替换），且希望**最大限度保住原片 1080p/4K 实拍背景、色调、镜头畸变和光影质感**。
- 预算敏感、希望锁定 `doubao-seedance-2-5-flash-261115` 产出接近旗舰模型 + 后期精修成片质量的团队流程。

### 边界与进阶扩展
- **前景遮挡处理**：若新参考视频中存在路灯杆、树干或前景人物频繁从替换主体前方穿行遮挡，只需在 Phase 3 的蒙版步骤增加一层前景语义分割/抠像（如 SAM2 / 深度遮挡估计），把前景遮挡物从合成蒙版中减去即可。
- **需要 60fps 极速丝滑成片时**：可在 24fps 分层合成版后，对局部主体走廊做光流补帧或在 60fps 原片底板上做 24→60fps 主体光流插值，保持背景原生 60fps。
- **非 HDR 平台分发**：若发布渠道不支持 HLG（如部分老旧浏览器或强制 SDR 播放器），可保留 `final-composited-1080p-with-audio.mp4` 作为 HDR 母版，另行在 DaVinci Resolve 或经视觉校对的 LUT 下转出一版 Rec.709 SDR 分享片。
